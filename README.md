# API de Controle Financeiro Pessoal (ODS 1 e ODS 12)

API desenvolvida em **NestJS** e **MongoDB** para o gerenciamento de finanças pessoais, com foco em apoiar a Erradicação da Pobreza (**ODS 1**) e incentivar o Consumo Responsável e Sustentável (**ODS 12**) através do registo de hábitos de consumo consciente e cálculo automático de gastos por impulso.

## 🚀 Tecnologias Utilizadas
- **Node.js** (v18+)
- **NestJS**
- **TypeScript**
- **MongoDB / Mongoose** (MongoDB Atlas)
